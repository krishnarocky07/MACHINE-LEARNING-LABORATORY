Scikit-learn ColumnTransformer Pipeline Architecture

Numerical Features (4) Current Stock, Previous Consumption, Daily Usage, Delivery Time → StandardScaler()
+
Categorical Features (2) Medicine Name, Medicine Category → OneHotEncoder(handle_unknown='ignore')
→
Combined Feature Space Fitted strictly on 80% training data → Regressor Estimator

Zero Data Leakage Guarantee: Preprocessing scalers and encoders are fitted solely on the training partition (560 samples) and applied to the held-out test partition (140 samples) and incoming live user queries.

🎯 Rigorous Model Selection Rationale

In accordance with strict machine learning best practices, model selection was determined by the lowest 5-Fold Cross-Validation Root Mean Squared Error (RMSE) computed solely on the training set. {{ metadata.model_metadata.selected_algorithm }} achieved superior generalization (CV RMSE = {{ metadata.model_metadata.cross_validation_results[metadata.model_metadata.selected_algorithm].mean_rmse }} units) and was exported as the deployment pipeline. The held-out test data was never accessed during model comparison or tuning.
